# 💪 Power Fit Academia Alves

Landing Page responsiva desenvolvida para a atividade prática do SENAI São Paulo.

## 📌 Objetivo

Criar uma página moderna para divulgação da academia Power Fit, apresentando modalidades esportivas, planos e informações de contato, utilizando tecnologias Front-End.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* jQuery

## 🏋️ Modalidades

* Musculação
* Funcional
* Cross Training
* Pilates
* Spinning
* Natação

## ✨ Funcionalidades

* Navbar responsiva
* Banner principal
* Catálogo com 6 cards
* Barra de pesquisa dinâmica
* Modo escuro
* Mostrar/Ocultar conteúdo com jQuery
* Formulário de contato
* Mensagem de confirmação
* Contador automático
* Carrossel Bootstrap
* Botão Voltar ao Topo
* Efeitos Hover e Scale
* Layout totalmente responsivo

## 📱 Responsividade

O projeto foi desenvolvido para:

* Desktop
* Notebook
* Tablet
* Smartphone
